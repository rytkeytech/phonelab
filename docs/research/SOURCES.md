A source marked **unavailable** was not read. It must not be cited as support for any claim.

Tiers (highest first):
1. Manufacturer service manuals and technical docs
2. Chipset vendor documentation
3. Component datasheets and vendor application notes
4. Legitimately published schematics and boardviews
5. Repair documentation with traceable measurements
6. Independent investigations with reproducible findings
7. Standard electronics references (general principles only)

Not evidence: search snippets, forum guesses, AI-generated diagrams, videos without visible measurements, or the same claim repeated across sites.
